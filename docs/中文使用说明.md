# 计时器中文使用说明

## 打开网页

进入项目目录，按照原 README 的方式启动本地静态服务。只在自己的电脑上访问时，可以把服务绑定到本机。

~~~powershell
python -m http.server 8000 --bind 127.0.0.1
~~~

打开 `http://127.0.0.1:8000/`。结束使用时，回到启动服务的窗口按 `Ctrl+C`。这次验证了静态服务可以从该地址返回首页、样式和脚本。使用 Edge 直接打开 `index.html` 时，下面的基本操作也已实际操作确认。

## 基本操作

1. 打开网页后，默认是 **Focus（专注）**，显示 **25:00**。
2. 点 **Start（开始）**，数字开始倒数。点 **Pause（暂停）** 后，数字停住。需要继续时，再点开始按钮。
3. 点 **Reset（重置）**，回到当前模式设置的时间。例如默认专注模式会回到 **25:00**。
4. 点右上方的齿轮图标，找到 **Focus duration (min)**。把专注时长改成 **10**，点到输入框外，计时器显示 **10:00**。刷新网页后设置仍在。练习结束后，可以把它改回 **25**。
