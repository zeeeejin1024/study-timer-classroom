# 计时器中文使用说明

## 在本机启动

本项目是静态网页，无需构建或安装项目依赖。按 README 的 Python 方式，在装有 Python 3 的电脑上打开项目根目录（含 `index.html`），在该目录的终端运行：

```sh
python -m http.server 8000
```

保持终端开启，在浏览器访问 <http://localhost:8000>。结束时回到终端按 Ctrl+C。README 也列出了 `npx serve .`，使用该方式时请打开终端显示的地址。

也可以用本机 Edge 直接打开 `index.html`。下面的按钮操作记录来自这种打开方式。

## 使用计时器

1. **开始**：选择 Focus（专注）、Short Break（短休息）或 Long Break（长休息），点击倒计时下方的 Start。
2. **暂停与继续**：点击 Pause 保留剩余时间，再点 Start 从暂停处继续。
3. **重置**：点击 Reset，倒计时停止并回到当前模式设定的完整时长。
4. **修改专注时长**：在 Focus 模式下，点击右上角齿轮，在 Settings 的 **Focus duration (min)** 中输入分钟数，再点到输入框外。例如，输入 10 后，表盘显示 10:00，等待你点击 Start。

## 本次实机记录

- 本机 Edge 直接打开首页，默认显示 25:00。点击 Start 后开始倒数，点击 Pause 后停住，点击 Reset 后回到 25:00。
- 专注时长改为 10 分钟后显示 10:00，刷新后仍为 10:00。测试结束时已将专注时长恢复为 25 分钟。
- 另用本地静态服务请求 `index.html`、`style.css` 和 `script.js`，三个请求均返回 HTTP 200。

暂停后继续、休息模式和其他设置仅核对了源码。长时间计时精度、提醒音、手机端和部署均未验证。
